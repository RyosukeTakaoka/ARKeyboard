# A Virtual Keyboard Based on True-3D Optical Ranging(EPFL, BMVC 2005)

- 著者: Huan Du, Thierry Oggier, Felix Lustenberger, Edoardo Charbon
- 発表: British Machine Vision Conference (BMVC) 2005, pp. 220–229, DOI 10.5244/C.19.27
- 出典 URL:
  - https://bmva-archive.org.uk/bmvc/2005/papers/151/paper.pdf
  - https://infoscience.epfl.ch/record/87512
  - https://www8.cs.umu.se/research/ifor/dl/Sensors/3Dcams/BMVC05.pdf
- **原文: 未確認**(上記サイトへの接続が環境のネットワーク設定で拒否された)。
  以下は検索結果に出た要旨・抜粋による二次情報です。

## 入力
- パターン投影機で面に QWERTY キーボードの絵を映す。
- 真の 3D 距離カメラ(Time-of-Flight 方式。解像度 160×124 画素、LED を 20 MHz で変調)で、深度と濃淡画像を撮る。

## 手法
- あらかじめ撮った「手が無いときの基準の深度」と比べて手の領域を見つける。
- 手の輪郭を解析して指先を見つける。
- 指に沿った**深度の曲線(depth curve)**の形を、いくつかの特徴モデルに当てはめて、打鍵かどうかを判定する
  (指を持ち上げたときと面に触れたときで曲線の形が違う)。
- 打鍵した位置を全体の座標系に変換して、どのキーかを決める。人手の介入なしに全自動で動く、と述べている。

## 出力
打鍵イベントと押されたキー。

## 使ったデータ・評価指標と数値
**不明**。検索結果からは、打鍵が正しく検出された追跡例が示されていることは分かったが、
体系的な正解率の数値は見つからなかった(原文未確認)。

## 限界(分かる範囲)
- 専用の ToF カメラと投影機が必要(後の研究でも、3D 撮像装置が必要な点が指摘されている)。
- 160×124 という低い解像度。

## このアプリへの取り入れ方
- 「深度で、指が面に触れているかを判定する」考え方は、LiDAR 搭載 iPhone の ARKit scene depth
  (約 256×192)で**既存 API による代替**ができる。
- すでに実装済み: キャリブレーション時に「指先の深さ − 手のひらの深さ」を記録し、タップの瞬間に
  その高さまで指が下りていなければ入力しない(空中で止めただけの誤入力を防ぐ)。
