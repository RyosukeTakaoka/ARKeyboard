# Usability Guided Key-Target Resizing for Soft Keyboards(当たり判定の動的な変化)

7-0 の「ソフトキーボードのタッチ位置と言語モデルを統合する研究」と、
「Apple 型の動的なヒット領域(事前確率の変化で実効的な当たり判定が広がる)」の理論的な裏付けとして調べた。

- 著者: Asela Gunawardana, Tim Paek, Christopher Meek(Microsoft Research)
- 発表: IUI 2010, pp. 111–118
- 出典 URL:
  - https://www.microsoft.com/en-us/research/publication/usability-guided-key-target-resizing-for-soft-keyboards/
  - https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/paper-final.pdf(読んだ版)
- **原文: 確認済み(全文)**

## 入力
タッチ位置 (x, y) と、それまでに打ったキーの履歴。

## 手法
- Goodman らの「情報源・通信路(source-channel)」の考え方: 打ちたいキー k の確率(言語モデル pL(k|h))×
  そのキーを狙ったときに位置 l に触れる確率(タッチモデル pT(l|k))が最大のキーを返す。
- タッチモデル: キーごとの**全共分散の2変量ガウス分布**。学習は**共役事前分布による MAP 推定**
  (平均の事前分布はキーの中心、共分散の事前分布は全キー共通の対角共分散を中心にする)。
  → データが少ないキーは「全体の平均」に引き寄せられる(このアプリの個人適応の縮小推定と同じ考え方)。
- 言語モデル: Kneser-Ney 平滑化した**キーの 8-gram**(USENET から集めた 850 万文字で学習)。
  言語モデルの確率は**指数の重み w を掛けて**(pL^w)、タッチモデルとの強さの釣り合いを取る(w は検証データで最適化)。
- **キーの当たり判定(key-target)** = 「そのキーの pL·pT が他のどのキーより大きい場所」の集合。
  履歴によって当たり判定の形が変わる(=動的リサイズ)。
- 問題点: 言語モデルがあり得ないと判断したキーは、当たり判定が小さくなりすぎたり消えたりして、
  **見えているキーの真ん中を押しても入力できない**ことが起きる。
- 提案: **アンカー(錨)**。各キーの中央の一定範囲は、どんな履歴でも必ずそのキーになるようにする。
  著者らは、これを保証するには「他のキーのタッチモデルが、そのアンカーの範囲では確率 0」になるよう、
  タッチモデルの範囲を制限する必要があることを証明している。

## 出力
1回の打鍵ごとに、入力するキー(オンライン)。

## 使ったデータ
- 参加者 9 人。4.2 インチの試作端末で、お題の文を打つ。狙ったキーかその隣を押せば進む仕組みで、
  「どのキーを狙って、どこを押したか」のデータを集めた。
- 評価用: 標準のお題、メール、検索語、URL の4種類。

## 評価指標と数値
- KeystrokeErrorRate(狙ったキーを正しく返せなかった割合)と MSD 誤り率(編集距離による誤り率)。
- 最適なアンカーは 6×60 ピクセル(キーは約 46×100 ピクセル)。
- アンカー付きの動的リサイズは、固定の当たり判定に比べて平均の打鍵誤りを
  **17% / 6% / 8% / 13%**(標準 / メール / 検索語 / URL)相対的に減らした(McNemar 検定で p < .01)。
- アンカーなしの従来の動的リサイズは、標準とメールで固定より **10% 悪化**した。
- アンカー付きは、固定が正しく従来法が誤った場面の 22% を正し、従来法の訂正の 96% を保った。

## 限界(著者らの記述)
- 実際の利用者が「使いやすい」と感じるかは、利用者実験で確かめていない(今後の課題)。
- 大きく高解像度な画面だったため、ぶれたデータが想定より少なかった。
- タッチモデルや言語モデルの利用者への適応は今後の課題。

## このアプリへの取り入れ方
- 空間タッチモデル(SpatialTouchModel)= 指×キーごとの2変量ガウス、学習は共役事前分布による MAP(縮小推定)。
- 事後確率 ∝ pT(位置|キー, 指) × pL(キー|文脈)^w。w は設定で変えられ、評価ツールで最適化する。
- **アンカー**を実装する(キーの中央の一定割合の範囲は、文脈に関係なく必ずそのキー)。割合は設定で変更可能。
- 当たり判定ビュー: 各点で事後確率が最大のキーで色分けすると、上の key-target そのものになる。
